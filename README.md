# Admin Future Toolbox

🧰 Набор полезных инструментов для системных администраторов Windows и Linux.

## 📦 Что внутри
- **Windows**  
  - `Clear-DiskSpace.ps1` — очистка временных файлов, логов и кэша обновлений.  
- **Linux**  
  - `backup.service` + `backup.timer` — шаблон для systemd-таймера.  
- **Zabbix**  
  - `disk_free_gb_trigger.yaml` — триггер «осталось <10ГБ» вместо процентов.  

## 🚀 Как использовать
Подробности по каждому инструменту смотрите в соответствующих папках.
